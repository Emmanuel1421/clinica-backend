# Projeto Clínica

Este é o backend do sistema de clínica para gerenciamento de pacientes e produtos.

## Tecnologias Utilizadas
- Node.js
- TypeScript
- Express / Fastify (A definir)
- PostgreSQL

## Instalação

```bash
npm install
```

## Configuração

Copie o arquivo `.env.example` para `.env` e configure as variáveis de ambiente necessárias.
Não adicione credenciais reais no repositório.

## Execução

```bash
# Desenvolvimento
npm run dev

# Produção
npm start
```
